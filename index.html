    Designed for untrusted repositories

    Static inspection. No install scripts. No repository execution.

    ForkWise reads public metadata and a bounded set of high-value text artifacts. It does not run package managers, tests, shell scripts, Dockerfiles, Makefiles, or repository-controlled workflows.
