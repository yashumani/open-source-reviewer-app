# ForkWise Support

ForkWise is a community preview. Support is provided on a best-effort basis through GitHub.

## Use the right channel

- **Bug or unexpected behavior:** use the Bug report issue form.
- **False positive:** use the False positive issue form and provide only public, non-sensitive evidence.
- **False negative or missing signal:** use the False negative issue form.
- **Feature idea:** use the Feature request form.
- **Analyzer rule:** use the Analyzer rule proposal form.
- **Documentation:** use the Documentation issue form.
- **Security vulnerability:** follow `SECURITY.md`; never disclose exploit details or credentials publicly.
- **Conduct concern:** follow `CODE_OF_CONDUCT.md`.

## Information to include

Provide the public repository URL, analyzed commit when available, intended-use context, expected result, actual result, and a minimal reproduction. Remove credentials, personal data, private repository content, and regulated data.

## Service expectations

ForkWise does not provide guaranteed response times, security certification, legal advice, or production adoption approval. Reports are decision support based on bounded static evidence.
