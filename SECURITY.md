# Security Policy

This repository is an early preview. Do not submit real credentials, private repository content, or regulated data to the public browser application.

Report a suspected vulnerability privately through the repository owner's established private contact channel rather than opening a public issue containing exploit or credential details.

The current product performs bounded static reads of public GitHub repositories and does not execute repository-controlled code. See [`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md) for the threat model and known limitations.
