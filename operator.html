Hard safety boundary

Inspection without execution

The runner calls GitHub’s public REST API, pins the default branch to one commit, and reads a bounded set of UTF-8 text artifacts. It never runs package managers, tests, shell scripts, Dockerfiles, Makefiles, workflows, or application code.
